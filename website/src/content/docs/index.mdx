Zendrite is a second-generation Matrix homeserver written in Go!
Following the microservice architecture model, Zendrite is designed to be efficient, reliable and scalable.
Despite being beta, many Matrix features are already supported.

This site aims to include relevant documentation to help you to get started with and run Zendrite.
Check out the following sections:

- **[Installation](/installation/planning)** for building and deploying your own Zendrite homeserver
- **[Administration](/administration/createusers)** for managing an existing Zendrite deployment
- **[Development](/development/contributing)** for developing against Zendrite
